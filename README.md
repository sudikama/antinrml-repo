# antinrml-repo

CloudStream extension repository by sudikama.

## How to Add

1. Open CloudStream app
2. Go to **Settings** → **Extensions** → **Add repository**
3. Enter this URL:
   ```
   https://raw.githubusercontent.com/sudikama/antinrml-repo/builds/repo.json
   ```

Check the `builds` branch for available `.cs3` files.
